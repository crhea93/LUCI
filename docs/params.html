Parameter Calculations

In this file we have the functions used to calculate the velocity, the velocity dispersion (broadening), and the flux as well as their uncertainties.

Fit Parameter Calculations

Backward-compatibility shim.

The velocity / broadening / flux conversions moved to LUCI.fitting.parameters. This module re-exports them so existing imports keep working. Prefer importing from LUCI.fitting.parameters in new code.
